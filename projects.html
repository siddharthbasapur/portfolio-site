SafeMed Automatic Pill Organizer
Arduino - Embedded Systems - Circuit Design - CAD

SafeMed is an Arduino-controlled automatic pill organizer designed to make medication routines easier and safer through simple keypad input and servo-based compartment positioning.

I integrated custom circuitry, embedded control logic, and CAD-designed components to create a functional prototype that connects physical movement with user input.

Arduino Embedded Systems Circuit Design CAD Hardware Prototyping
  • Designed and built an Arduino-controlled automatic pill organizer
  • Used keypad input and servo-based compartment positioning
  • Integrated custom circuitry, control logic, and CAD-designed parts
  • Created a functional prototype focused on medication organization

IBD Life Starter
Health Tech - Web Design - Data Aggregation - Patient Support

IBD Life Starter is a health-focused website prototype connected to my work with the Health and Design System Integration Lab. The goal is to help people newly diagnosed with IBD understand lifestyle topics through organized, source-aware information.

The project is designed around a future pipeline that auto-aggregates information from web resources, organizes it into a reviewable database, and displays approved summaries on the website.

Health Tech Web Design IBD Support Data Organization Web Aggregation Patient Resources
  • Built as a resource page for people newly diagnosed with IBD
  • Designed to separate trusted medical information from patient experience themes
  • Planned pipeline: aggregate web resources, store reviewed content in Excel, and publish approved summaries
  • Developed through HDSI Lab work supporting a health-focused research prototype

Health and Design System Integration Lab Connection

As a Design Volunteer in the Health and Design System Integration Lab, I developed a prototype website for a health condition by auto-aggregating information from various web resources.

This work connected design, health technology, and research support by turning scattered online information into the foundation for a structured prototype. The prototype served as the basis for an R21 NIH application.

Health Design Research Prototype Web Aggregation Health Technology R21 NIH Application
  • Developed a prototype website for a health condition using auto-aggregated web resources
  • Organized online information into a clearer structure for health-focused users
  • Connected web design, research support, and health technology
  • Created prototype work that served as the basis for an R21 NIH application

Arduino Agricultural Drone Attachment
Arduino - Embedded Systems - Mechanical Design

This project focused on designing and building an Arduino-controlled drone attachment to distribute fertilizer across uneven agricultural terrain.

I integrated servo-controlled hardware and custom electronics, then troubleshot power and control issues to produce a functional prototype with a practical agricultural use case.

Arduino Embedded Systems Mechanical Design Servo Control Agriculture
  • Designed and built an Arduino-controlled drone attachment for fertilizer distribution
  • Integrated servo-controlled hardware and custom electronics
  • Troubleshot power and control issues during prototype development
  • Focused on helping farmers reach rough or uneven terrain
