SafeMed Automatic Pill Organizer
Arduino - Embedded Systems - Circuit Design - CAD

SafeMed is an Arduino-controlled automatic pill organizer designed to make medication routines easier and safer through simple keypad input and servo-based compartment positioning.

I integrated custom circuitry, embedded control logic, and CAD-designed components to create a functional prototype that connects physical movement with user input.

Arduino Embedded Systems Circuit Design CAD Hardware Prototyping
  • Designed and built an Arduino-controlled automatic pill organizer
  • Used keypad input and servo-based compartment positioning
  • Integrated custom circuitry, control logic, and CAD-designed parts
  • Created a functional prototype focused on medication organization

IBD Life Starter
Health Tech - Web Design - Data Aggregation - Patient Support

IBD Life Starter is a health-focused website prototype connected to my work with the Health and Design System Integration Lab. The goal is to help people newly diagnosed with IBD understand lifestyle topics through organized, source-aware information.

The project is designed around a future pipeline that auto-aggregates information from web resources, organizes it into a reviewable database, and displays approved summaries on the website. This prototype served as the basis for an R21 NIH application.

Health Tech Web Design IBD Support Data Organization Web Aggregation Patient Resources
  • Built as a resource page for people newly diagnosed with IBD
  • Designed to separate trusted medical information from patient experience themes
  • Planned pipeline: aggregate web resources, store reviewed content in Excel, and publish approved summaries
  • Developed through HDSI Lab work supporting an R21 NIH application concept
